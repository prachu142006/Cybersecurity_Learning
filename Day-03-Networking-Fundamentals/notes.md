# Day 3 – Networking Fundamentals

## 1. What is a Network?
A network is a group of connected devices that communicate and share information.

## 2. IP Address
An IP address is a unique logical address used to identify a device on a network.

Example: 192.168.1.10

## 3. MAC Address
A MAC address is a hardware address assigned to a network interface.

## 4. Port Number
A port number identifies a particular service or application running on a device.

Common ports:
- 22 – SSH
- 53 – DNS
- 80 – HTTP
- 443 – HTTPS
- 3306 – MySQL

## 5. Protocol
A protocol is a set of rules used by devices to communicate.

Examples:
- HTTP – Transfers website information.
- HTTPS – Secure website communication.
- DNS – Converts domain names into IP addresses.
- FTP – Transfers files.
- SSH – Secure remote access.
- TCP – Reliable data delivery.
- UDP – Connectionless communication.

## 6. TCP vs UDP

TCP:
- Connection-oriented.
- Reliable data delivery.
- Maintains packet order.

UDP:
- Connectionless.
- Delivery is not guaranteed.
- Generally faster with less communication overhead.

## 7. DNS
DNS stands for Domain Name System. It converts domain names into IP addresses.

## 8. Default Gateway
A default gateway connects a local network to other networks.

## 9. Importance of Networking in SOC
A SOC Analyst uses networking knowledge to:
- Investigate suspicious IP addresses.
- Monitor network traffic.
- Identify unusual ports.
- Investigate suspicious connections.
- Troubleshoot connectivity problems.
