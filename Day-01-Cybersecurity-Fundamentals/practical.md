# Day 01 - Practical Lab

## Objective
Understand my Kali Linux system and basic network information.

## Commands Used

1. whoami - Identify current user.
2. hostname - Identify computer name.
3. uname -a - Check system information.
4. ip -br addr - Check IP addresses.
5. ss -tuln - Check listening ports.
6. journalctl -n 30 --no-pager - Review system logs.

## Learning Outcome
I learned basic Linux system investigation
and how SOC Analysts use system information
and logs during security monitoring.

## Observation
I performed basic investigation on my own Kali Linux machine.
