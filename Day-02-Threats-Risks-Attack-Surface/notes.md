# Day 02 - Threats, Risks and Attack Surfaces

## 1. Cyber Threat
Anything that can potentially harm a system.

## 2. Vulnerability
A weakness in a system that can be exploited.

## 3. Risk
Possibility of damage when a threat exploits a vulnerability.

## 4. Attack Surface
All possible entry points an attacker may target.

## 5. Security Event
An activity recorded by a system or network.

## 6. Security Incident
An event that compromises or threatens security.

## 7. Brute Force Attack
Repeated password guessing to gain unauthorized access.

## SOC Analyst Learning
A SOC Analyst monitors alerts, investigates suspicious
activities and identifies potential security incidents.
